## Resultado

A conta institucional aprovada foi autenticada pela interface e passou pela verificação de identidade exata do painel (ID, e-mail, confirmação e status). A consulta autenticada da coleção PTPRegistrosMembros retornou 403. O acesso gerencial NÃO foi concluído.

O grant especial existente usa o ID de membro em userId, campo documentado para usuários Wix. Sua presença não comprova autorização efetiva de uma sessão de membro; o teste real recusou essa leitura. Não foram ampliadas permissões de coleções nem expostos dados.

## Pendência operacional

Configurar uma integração de servidor com credencial administrativa apropriada, validando o membro institucional exato antes de cada consulta. O último log de inicialização localizado no Render (23/11/2026 22:48 UTC) informa admin credentials configured: false. O frontend publicado ainda consulta CMS diretamente; configurar um segredo isoladamente não conclui a migração.

Antes de ativar: reconciliar código efetivamente implantado e branch, adaptar as consultas paginadas das 21 fontes para a rota protegida, configurar credencial apenas no servidor, testar dono real e membro sem autorização, verificar sessão expirada e leitura/exportação. Não retirar o gate privado, não tornar CMS público ou legível a todos os membros.
